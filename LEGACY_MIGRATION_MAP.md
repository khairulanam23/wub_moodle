# WUB Moodle Legacy Migration Mapping

## Overview

This document establishes the definitive migration mapping between the preserved reference legacy WUB Moodle implementation (`legacy/wub-moodle-original` branch, commit `b8ee2f238ce1f64393060a4d69175535bf983365`, tag `legacy-before-new-moodle`) and the active Moodle 5.2.2+ Dockerized project (`main` branch in `/home/phant0m/Phantom/moodle`).

All legacy business logic has been audited, extracted, and migrated cleanly into supported Moodle 5.2.2+ plugins, configuration, and theme settings without Moodle core modifications or legacy core contamination.

## Technical Invariant Verification

1. **Moodle 5.2.2+ Architecture**: Target codebase strictly runs on Moodle 5.2.2+ (Build: 20260911), PHP 8.4, and MariaDB 11.8.
2. **Zero Core Modifications**: Zero files modified under `moodle/lib/`, `moodle/admin/`, `moodle/course/`, etc.
3. **No Legacy Core Contamination**: No files from legacy branch `legacy/wub-moodle-original` were copied into core or theme directories.
4. **No Competing Implementations**: All authentication consolidated into `local_wub_auth`; all bulk enrolment consolidated into `local_bulk_enrolment`. No duplicate plugins active.
5. **Authoritative Financial Clearance**: `\local_wub_auth\service\financial_clearance_service` acts as single source of truth for both Moodle and ExamController.
6. **Zero Hardcoded Secrets / Data**: Zero credentials, tokens, passwords, or database dumps committed.
